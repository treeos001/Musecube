# Security Policy

Please report security vulnerabilities privately by email to **shukuinan@musecube.app**. Do not open a public GitHub issue for security problems.

Include the Musecube version, your macOS version, and steps to reproduce. This address receives mail only; replies aren't guaranteed.

# 安全政策

请写明 Musecube 版本、macOS 版本和复现步骤。这个地址只用于收信，不保证回复。
